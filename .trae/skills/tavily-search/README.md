# 🔍 tavily-search

**可以直接将整个 repo 丢给 OpenClaw 安装！**

Tavily AI search API - Optimized search for AI agents.

## Install

```bash
git clone https://github.com/veithly/tavily-search.git
cp -r skills/tavily-search /home/google/clawd/skills/
```

**Or give repo URL to OpenClaw → It will auto-install!**

## Usage

```bash
./skills/tavily-search/scripts/search "latest AI news"
```

## Environment

```bash
export TAVILY_API_KEY="your-api-key"
```

Get API key: https://tavily.com/
